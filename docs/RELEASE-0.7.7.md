# SCNet Agent 0.7.7 (HarmonyOS + 原生 Android)

> **设置页只留用户关心的内容**：把开发调试项从 UI 里全部撤掉。

## 移除的项（用户不关心 / 属于调试能力）

| 项 | 为什么移除 |
| --- | --- |
| 更新源（JSON 地址） | 开发联调用；仓库已公开，默认走 GitHub 即可 |
| API 基地址（mock） | 仅我联调 mock 平台时用 |
| 当前通道 | 输入区的通道 chip 已经表达了同一个信息，重复 |
| 集群调度器 | 内部 SLURM id，用户无需知道 |
| 网关 key / 密钥地址 | 账号额度凭证，任何形式的展示都不合适 |
| 上次崩溃 / 复制诊断 | 支持手段，不是用户功能（崩溃时仍会自动捕获并提示） |
