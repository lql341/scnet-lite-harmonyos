## 11.1 Markdown 能力对照（Android 0.6.0 实测）

| 语法 | 结果 |
| --- | --- |
| `#`~`######` | ✅ 字号分级（H4/H5/H6 递减） |
| `**粗**` `*斜*` `` `码` `` `~~删除~~` | ✅ |
| `- ` / `1. ` / 缩进子项 | ✅ 三级缩进、有序嵌套 |
| `- [ ]` / `- [x]` | ✅ ☐ / ☑ |
| `>` / `> >` | ✅ 连续引用合并，嵌套缩进 |
| 表格 + `:---:` 对齐 | ✅ 列宽按内容测量，不折断数字；支持左/中/右 |
| 代码块（含语言标签、复制） | ✅ 未闭合也照常渲染（流式） |
| `![alt](https://…)` / 裸图片链接 | ✅ |
| `[img](oss:///…)` | ✅ 映射到 oss 公共资源（与官方客户端一致） |
| `[文字](url)` / 裸 URL | ✅ 可点击（代码块内不转链接） |
| 行内公式 `$x^2$` | ⛔ 原样显示（无 KaTeX，HAP 同） |
| HTML 标签 `<b>` | ⛔ 原样显示（不解析，避免注入） |
| `H~2~O` 下标 | ⛔ `~` 与删除线语法冲突，按文本显示 |

## 12. 结论

除「真实账号联调」这一条（需要真机 + 账号）外，Android 版与 HAP 的功能面一致；
两处实现方式不同但交互等价：长会话渲染（LazyForEach ↔ 窗口 + 加载更早）、
消息长按（原生上下文菜单 ↔ 直接复制）。

## 13. UI 对齐（以 HAP 为准，2026-11-11 真机截图比对）

对照设备：HAP 装在 <HarmonyOS 测试机>（HarmonyOS 7.0 / API 26），Android 装在 Redmi <Android 测试机> + Android 11 模拟器。

| 元素 | HAP（基准） | Android 已对齐 |
| --- | --- | --- |
| 顶栏状态 | `● 网关已就绪`（不带模型名） | ✅ 去掉「· 模型名」 |
| 输入框 placeholder | `发消息…` | ✅ |
| 输入区结构 | `＋` / `场景 ▾` / `当前通道 ▾` / `↑`（空输入半透明，生成中红底 ■） | ✅ |
| 输入区底注 | `内容由 AI 生成，请自行核对` | ✅ |
| 消息来源标注 | 在气泡**上方**（如「智能体服务」） | ✅ 从下方移到上方 |
| H1 标题 | 左侧 accent 色条 | ✅ |
| 表格 | 卡片式（表头一行 + 首列标题 + 键:值） | ✅ 由真表格改为卡片式 |
| 引用 | 左侧 `accentSoft` 浅条 | ✅ |
| 列表 | 5px 圆点 / `1.` 序号（textFaint） | ✅ |
| 抽屉头 | 头像 + 名字 + `已登录 · 超算互联网` + ✕ | ✅ |
| 新对话 | 整宽主色按钮，文字靠左 `＋ 新对话` | ✅ |
| 服务入口 | 4 张独立卡片（HPC / ＋ / AI / OCR + 副标题 + ›） | ✅ 由整块容器改为独立卡片 |
| 本机会话 | 段标题带数量；行=`标题（当前项 accent）+ N 条 · 模型 + ✕` | ✅ |
| 平台历史 | 段标题带数量 + `刷新`；行=标题 + `状态 · MM-DD` + 绿点 | ✅ |
| 退出登录 | 浅红底圆角按钮，整行居中 | ✅ |
| 设置入口 | 点头像/名字进入（抽屉里无独立「设置」行） | ✅ 去掉多余行 |

比对过程中顺带修掉的崩溃：会话行去掉 `›` 后按索引取控件导致 `ClassCastException`
（被应用内崩溃兜底界面接住并显示堆栈），改为按 tag 查找。
