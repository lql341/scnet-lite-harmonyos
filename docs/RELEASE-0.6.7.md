# SCNet Agent 0.6.7 (HarmonyOS + 原生 Android)

> 按 **HAP 为准** 继续收内页：这一轮是**设置页（含其所有内部面板）**与**作业详情页**。

## 设置页（整体重写为 HAP 结构）

| 区块 | 内容（= HAP） |
| --- | --- |
| 顶栏 | `‹ 设置`（无副标题） |
| 头像卡 | 居中 72px 头像 + 姓名 20px + `已登录 · 超算互联网` |
| 信息卡 | 5 行：账号 / 集群账号 / 集群（带「N 个可选」，点击切集群）/ 当前通道 / 集群调度器 |
| 自定义模型 | 单行 → 面板 |
| 外观 | **三组分段控件**：跟随·浅色·深色 / 主题色（带色点）/ 字体大小 小·标准·大 / 语言 中文·English |
| 检查更新 | 单行，右侧显示当前版本 |
| 关于 | 单行 → 弹层（版本 / 非官方声明 / 作者 / 项目） |
| 退出登录 | 浅红底按钮 |

Android 额外保留「调试」区（API 基地址 / 更新源 / 上次崩溃 / 复制诊断），iOS/HAP 无此需求。

## 设置内部面板

- **主题色**：圆形色板网格（4 列，选中打勾，标题「主题色 / 选中即刻生效，会记住」）
- **头像**：分组网格（卡通 6 / 风景 4 / 字母 2）+ 其他（默认首字 / 从相册选 / 让智能体生成头像 →）
- **字体/外观/语言**：分段控件（选中项主色实心）
- **自定义模型**：7 个预设 chip + 名称/URL/Key/模型 + 「用平台网关 / 保存并启用」

## 作业详情页

- 顶栏：`‹ 作业 {id}` + **状态副标题**（运行中绿 / 异常红）+ `⟳` + **条件显示**「取消作业」pill
- 字段改成 HAP 的 **label 左（84px）+ value 右**两列样式，行间细分隔线（14 项，顺序与 HAP 一致）
- 日志卡标题改「输出日志」+ 右侧「读取」

## 顺带修复

- 设置页头像卡未撑满宽度导致姓名被裁（改用 MATCH_PARENT + 文本居中）
