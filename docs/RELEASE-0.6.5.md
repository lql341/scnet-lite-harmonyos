# SCNet Agent 0.6.5 (HarmonyOS + 原生 Android)

> 继续按 **HAP 为准** 收 UI：这一轮做「作业页」及其内页，以及设置里的两个面板。

## 作业页（JobPage）

| 项 | Android 之前 | 现在（= HAP） |
| --- | --- | --- |
| 顶栏 | 返回 + 标题 + 文件/提交 | `‹` + **作业 / 集群名** + `↻` `文件` `提交`(实心) `算力密钥` |
| 统计 | 一行灰字「配额：CPU …」 | **两张数字卡**：`空闲核 4739 / 共 3 个队列`、`配额 640 / DCU 8 · Job 20` |
| 集群切换 | 全量 chips | 只列**其他**集群描边 chip（当前在副标题） |
| 队列行 | 一行文字 | 名称 + `131 节点 · 单节点最多 64 核` + **右侧绿色大数字 739 / /8384** |
| 空态 | 一行灰字 | 居中卡片「当前没有运行中的作业」 |
| 底部 | 无 | `提交作业：点右上「提交」进入表单（默认只做校验与脚本预览）` |

## 设置内页

| 面板 | 之前 | 现在（= HAP） |
| --- | --- | --- |
| 配色 | 文字列表 | **圆形色板网格**（4 列，选中打勾，标题「主题色 / 选中即刻生效，会记住」） |
| 头像 | emoji 列表 | **分组网格**：卡通 6 / 风景 4 / 字母 2 + 其他（默认首字 / 从相册选 / 让智能体生成头像 →） |

## OCR 内页

顶栏改为 HAP 结构：`‹` + 「文字识别 / 支持图片与 PDF（证照/票据/手写）」+ 右侧「自检」pill；
模式名对齐 HAP「通用文字识别 / 文档解析 / 格式转换」。

## 联调支持

`Hpc` 现在也支持 `debugApiBase`（作业面可指向本地 mock），所以能在不接触真实 AK/SK 的前提下
复现 HAP 的作业页布局做像素级比对（本轮就是这么对的）。
